# Product: LAZARUS

**Pitch:** AI can rewrite old code in seconds. Lazarus puts the rewrite on trial against the original, then hands you a certificate and a Kiro spec of every behavior that changed.

- Category: Resurrection (Kiroween 2026). Case #1: Python 2 libraries to Python 3.12. Case #2: numpy 1.26 to 2.x.
- Public vocabulary is exactly four terms: **Autopsy, Trial, Certificate, Kiro spec**. Agent names and other jargon stay in secondary UI only.
- Honesty is the product. Never invent numbers, quotes, divergences or citations. Every metric shown must come from a real run. A divergence is never waived by the LLM; only a human ruling with a named rule marks it "Intentional".
- Graded results always come from the held-out trial (frozen rewrite hash, separate seed, separate strategies).
